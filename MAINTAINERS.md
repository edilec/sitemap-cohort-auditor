## Responsibilities

Maintainers are responsible for:

- reviewing changes to parsing, traversal, network access, limits, policy rules,
  and output compatibility;
- keeping supported Node.js versions and CI evidence accurate;
- coordinating private vulnerability reports and security releases;
- publishing releases from reviewed tags; and
- stating maturity, limitations, and breaking changes without overstating what
  the utility verifies.

Repository ownership does not guarantee a response or release deadline. See
[SUPPORT.md](./SUPPORT.md) for the public support boundary.

## Adding maintainers

Maintainer access is granted after sustained, reviewed contributions and an
explicit decision by the project owner. This file must be updated in the same
change that grants or removes maintainer responsibility.
