# Support

Sitemap Cohort Auditor is maintained as an open-source utility. Public support
is provided through GitHub on a best-effort basis; no response-time or
resolution-time commitment is implied.

## Where to ask

- For a reproducible defect, use the
  [bug report form](https://github.com/edilec/sitemap-cohort-auditor/issues/new?template=bug.yml).
- For a focused capability proposal, use the
  [feature request form](https://github.com/edilec/sitemap-cohort-auditor/issues/new?template=feature.yml).
- For a suspected vulnerability, use
  [private vulnerability reporting](https://github.com/edilec/sitemap-cohort-auditor/security/advisories/new),
  not a public issue.

Search existing issues before opening a new one. Include the utility version,
Node.js version, operating system, exact command, expected result, observed
result, and a minimal synthetic sitemap when it is safe to share.

## Support boundary

The maintainers can investigate behavior of this utility. They cannot provide
search-engine indexing guarantees, diagnose a private production site without
a reduced fixture, or operate a release pipeline on a user's behalf.

Never post credentials, private hostnames, customer data, analytics exports, or
an unredacted production URL inventory in an issue.
